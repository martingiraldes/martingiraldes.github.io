Política de privacidad

Proxmox Backup Rclone

Última actualización: 25 de noviembre de 2026.

Proxmox Backup Rclone es una aplicación de uso personal que utiliza Rclone y Google Drive API para administrar copias de seguridad de Proxmox.

Acceso a los datos

La aplicación solicita autorización OAuth 2.0 para acceder a Google Drive del propietario. Este acceso se utiliza para subir, consultar, verificar y administrar archivos de respaldo.

Uso de la información

Los datos se utilizan exclusivamente para las operaciones de respaldo autorizadas por el propietario.

No se venden datos personales ni se utilizan con fines publicitarios. No se ofrece acceso a otros usuarios.

Almacenamiento y seguridad

Los archivos de respaldo se almacenan en Google Drive. Las credenciales de autorización de Rclone se almacenan en la configuración local del sistema que ejecuta Rclone.

Conservación y eliminación

El propietario controla la conservación y eliminación de sus copias de seguridad. Puede revocar el acceso de la aplicación desde la configuración de su cuenta Google.
