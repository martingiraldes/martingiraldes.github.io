Proxmox Backup Rclone

Aplicación de uso personal para realizar copias de seguridad de servidores Proxmox en Google Drive mediante Rclone.

Funcionamiento

La aplicación utiliza Google Drive API y OAuth 2.0 para autorizar el acceso a la cuenta de Google del propietario.

No es un servicio comercial ni está disponible para terceros.
